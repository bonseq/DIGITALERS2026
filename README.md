Este repositorio contiene las prácticas y laboratorios del curso de **Automatización de Pruebas (Testing Automation)**. El objetivo principal del proyecto es aprender a automatizar flujos web utilizando Java y el framework de Selenium WebDriver hasta el momento.

## 📝 Descripción

El proyecto actual interactúa principalmente con la página de pruebas [Automation Exercise](https://automationexercise.com/). Se realizan pruebas de apertura de navegadores, navegación a URLs específicas, interacción con elementos del DOM (inputs, botones) y aserciones básicas.

> 💡 **Nota sobre la actualización del Framework:**  
> Este proyecto tiene practicas de **TestNG**, y JUnit hasta el moemnto.
> La practicase realiza con el objetivo de convertir el repositorio en un entorno de **práctica intensiva** para dominar los frameworks. Aquí se aplican de forma directa todos los conceptos y el material visto en el curso hasta el momento, aprovechando las capacidades avanzadas de TestNG (como manejo avanzado de anotaciones, suites de pruebas dinámicas y aserciones) para robustecer la automatización.

### Ejercicios desarrollados hasta ahora:
- Inicialización de navegadores (`ChromeDriver`, `FirefoxDriver`).
- Navegación web y maximización de ventanas.
- Búsqueda e interacción con elementos web usando localizadores (`By.id`, etc.).
- Envío de texto simulando teclado (`sendKeys`) y clics (`click()`).
- **Implementación de TestNG:** Refactorización de las pruebas unitarias para usar aserciones y anotaciones (`@Test`, `@BeforeMethod`, `@AfterMethod`) propias de este framework.

## 🛠️ Tecnologías y Herramientas

- **Lenguaje:** Java (JDK 8+)
- **Gestor de dependencias:** Maven
- **Framework de Testing:** **TestNG** *(Actualizado)*
- **Automatización Web:** Selenium WebDriver
- **IDE Utilizado:** Eclipse IDE

## 🚀 Requisitos Previos

Para clonar y ejecutar este proyecto, necesitaras tener instalado:

- [Java Development Kit (JDK)](https://www.oracle.com/java/technologies/downloads/)
- [Eclipse IDE para desarrolladores Java](https://www.eclipse.org/downloads/)
- Drivers actualizados para los navegadores que desees usar incluidos en tu PATH o configurados mediante Selenium Manager.
